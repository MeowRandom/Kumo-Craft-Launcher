# Loader icon sources

These icons are unmodified or minimally cropped copies of artwork published
in the official loader repositories. They are used only to identify the
corresponding loader in Kumo.

The vanilla application icon is not bundled. Kumo copies the official
light isometric grass-block artwork used by the version row from the locally
installed Minecraft for Windows package. This is the complete version-block
icon rather than the flat cloud texture or creeper app tile.
